# Portfolio Document Manager v2.0

## 🚀 Snelstart

### Optie 1: Executable (Aanbevolen)
1. Dubbelklik op `PortfolioDocumentManager.exe`
2. Vul je studentgegevens in
3. Begin met portfolio items toevoegen!

### Optie 2: Python (Fallback)
Als de .exe niet werkt of je krijgt GTK3 errors:

1. **Installeer Python 3.11+** van [python.org](https://www.python.org/downloads/)
2. Open PowerShell of Command Prompt in deze folder
3. Installeer dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Start de app:
   ```bash
   python main.py
   ```

## 📄 PDF Generatie

### Windows
- GTK3 DLL bestanden zitten al in deze folder!
- Als PDF generatie niet werkt, probeer de Python versie (zie Optie 2 hierboven)

### Handmatige GTK3 Installatie (alleen als nodig)
Als je toch GTK3 wilt installeren systeembreed:
- Download: [GTK3-Runtime Win64](https://github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Installer/releases)
- Installeer en herstart de applicatie

## 💡 Tips

- **Eerste keer**: Vul je studentgegevens in via het instellingenmenu
- **Semester wijzigen**: Instellingen → Semester selecteren
- **Feedback toevoegen**: Bewerk een portfolio item en scroll naar beneden
- **Document genereren**: Klik op "Document Inleveren" als je klaar bent

## 🐛 Problemen?

- **Exe werkt niet**: Gebruik Python versie (Optie 2)
- **PDF error**: Probeer Python versie met `python main.py`
- **Andere issues**: [GitHub Issues](https://github.com/RickMageddon/PortfolioDocumentManager/issues)
